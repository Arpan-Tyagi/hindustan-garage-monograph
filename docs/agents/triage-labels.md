# Triage Labels

The canonical triage roles mapped to the issue tracking vocabulary for this repository:

| Role in mattpocock/skills | Label in our tracker | Meaning |
| ------------------------- | -------------------- | ------- |
| `needs-triage`            | `needs-triage`       | Maintainer needs to evaluate this issue |
| `needs-info`              | `needs-info`         | Waiting on reporter/client for more information |
| `ready-for-agent`         | `ready-for-agent`    | Fully specified, ready for automated agent work |
| `ready-for-human`         | `ready-for-human`    | Requires human craft, workshop verification, or client sign-off |
| `wontfix`                 | `wontfix`            | Will not be actioned or out of scope |
