# Repository Guidelines: Hindustan Garage & Speed Parts

This repository contains the digital monograph and web application for **Hindustan Garage (Est. 1960, Prayagraj)** and its wholesale spare parts division **Speed Parts (Medical Chauraha)**.

## Agent skills

### Issue tracker
Issues and specs live as markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels
Uses canonical triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs
Single-context layout (`CONTEXT.md` + `docs/adr/`). See `docs/agents/domain.md`.

## Key Architectural & Aesthetic Guidelines
1. **Design Ethos: "Everything Is Important"**: Archival permanence, zero flashy 3D gimmicks, asymmetric 12-column museum grid, fine 1px rule lines (`#D6D1C4`).
2. **Color Palette**: Archival Parchment (`#F5F2EB`), Deep Coachbuilder Charcoal Ink (`#141413`), Heritage Marque Crimson (`#8C1813`), Royal Oxford Navy (`#12355B`), Warm Brass Accent (`#B4925A`).
3. **Typography**: Cormorant Garamond & Playfair Display for editorial headings, Plus Jakarta Sans for UI, JetBrains Mono for telemetry, bay indicators, GSTIN (`09ADQPA5477Q1ZN`), and OEM SKUs.
4. **Motion Discipline**: Native smooth scrolling, double-bezel nested hardware architecture, tactile button fill transitions (`cubic-bezier(0.19, 1, 0.22, 1)`).
